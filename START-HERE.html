邮件助手：Windows 快速开始

这是一个通过 MCP 提供邮箱读写能力的本地助手。Coremail 只作为可选邮件 provider；服务不会打开、点击或控制邮件客户端界面。

最短路径：完整解压 ZIP → 双击 INSTALL.cmd → 重启 Claude Code → 先调用 mail_config_status。

安装与升级

  1. 把 mail-mcp-server-*-windows-x64.zip 解压到新的普通目录，不要从压缩包预览窗口运行。
  2. 双击 INSTALL.cmd。首次安装和升级使用同一个入口；升级会保留配置并在新版本验证通过后原子切换。
  3. 安装失败会恢复原来的 MCP 注册和活动版本；新版本目录会保留供诊断。

首次配置和使用

  1. 双击 CONFIGURE.cmd，按提示选择 Windows Simple MAPI 或安全 IMAP/SMTP。密码只进入 Windows Credential Manager，不要粘贴到聊天。
  2. 需要查看文件时双击 OPEN-CONFIG.cmd。配置路径固定为 %USERPROFILE%\mail-mcp-server\config\settings.json。
  3. 重启 Claude Code，调用 mail_config_status、mail_config_reload，再调用 mail_check_connection。
  4. 发送邮件必须先准备并展示收件人、主题和附件；只有用户明确回复 确认发送 才能发送。

卸载、回滚和日志

双击 UNINSTALL.cmd 只移除 mail-mcp 的 Claude 用户级注册，默认保留配置、版本、回滚记录和日志。重新安装任意已验证版本即可回滚；不要手动删除被占用的版本目录。

本工程的状态、锁、日志和版本都在 %USERPROFILE%\mail-mcp-server\ 下。常见日志目录是 %USERPROFILE%\mail-mcp-server\logs。

执行策略提示：入口只对本次 PowerShell 子进程使用 -ExecutionPolicy Bypass，不会修改持久策略。若组织设置了 MachinePolicy 或 UserPolicy，请把 Get-ExecutionPolicy -List 和日志交给管理员。
